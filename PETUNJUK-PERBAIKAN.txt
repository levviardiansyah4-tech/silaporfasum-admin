PERBAIKAN SiLaporFasum Admin v10

1. Ekstrak ZIP.
2. Ganti index.html, admin.js, admin.css, dan admin-petugas.css di root repository GitHub Pages.
3. Commit changes dan tunggu deployment selesai.
4. Buka aplikasi admin lalu tekan Ctrl+Shift+R.
5. Pastikan Console menampilkan “SiLaporFasum Admin JavaScript v10 loaded” dan Network memuat admin.js?v=20261026-fix-simpan-v10.
6. Ubah status laporan dan klik Simpan Perubahan.
7. Jika muncul error RLS, buka SQL_PERBAIKAN_UPDATE_LAPORAN.sql, ganti placeholder email dengan email login admin yang tepat, lalu jalankan di SQL Editor Supabase project yang benar.
8. Logout-login kembali dan coba simpan lagi.

Catatan: jangan jalankan SQL sebelum placeholder email diganti. Jangan pernah memasukkan service_role/secret key ke file frontend.
