PERBAIKAN SiLaporFasum Admin v17 — GPS + FORM UPDATE

1. Ganti index.html dan admin.js di root repository GitHub Pages dengan file versi ini.
2. Commit/push perubahan dan tunggu GitHub Pages selesai deploy.
3. Buka website admin, tekan Ctrl+Shift+R (hard refresh), lalu login kembali.
4. Buka detail laporan. Bagian “Lokasi GPS dari pelapor” menampilkan koordinat dan tautan Google Maps jika kolom koordinat tersedia di tabel public.laporan.
5. Jika muncul “Koordinat GPS belum tersedia”, website user harus menyimpan koordinat ke tabel public.laporan. Kode admin mendukung nama kolom: latitude/longitude, lat/lng, lokasi_lat/lokasi_lng, gps_latitude/gps_longitude, atau koordinat_lat/koordinat_lng.
6. Tombol Simpan Perubahan kini mengambil form aktif dari modal detail untuk menghindari referensi form yang sudah lama.
7. Update status tetap menggunakan RPC silapor_admin_update_status_v14. Pastikan SQL fungsi RPC yang sudah digunakan sebelumnya tetap terpasang pada proyek Supabase yang benar.

Catatan: perubahan tampilan admin tidak dapat membuat koordinat muncul jika aplikasi user tidak menyimpan koordinat GPS ke database. Jangan memasukkan service_role/secret key ke frontend.
